# 03: 完成 Judge 结果校验与三类结果汇总

**What to build:** 调用方通过文本检测引擎获得完整的有风险、未发现风险或不确定结论，同时保留规则证据、语义裁判判断、执行失败与未完成信息。使用可控语义裁判验证全部汇总行为，不依赖真实模型或正则匹配器实现。

**Blocked by:** 01 — 关键词文本检测的最小闭环。

**Status:** resolved

- [x] 语义裁判独立接收待检文本、来源和调用方提供的必要任务上下文，不接收规则命中结果，不自动读取完整会话。
- [x] 对有效、未超限且引擎已初始化的文本，关键词或正则的正常命中和未命中均只触发一次语义裁判调用；多个规则不导致多次模型调用。
- [x] 校验结构化输出：合法三态结论、简短理由及允许为空的可疑原文证据；缺失字段、非法结论和不可解析输出记为输出无效，不从自由文本猜测结论。
- [x] 语义裁判证据必须能对应待检原文；不能对应时标记证据无效，不将生成内容作为原文，不据无效证据宣称检查通过。
- [x] 区分正常返回的语义不确定、服务异常、无效输出与证据无效，分别保留原因。
- [x] 必需检查完整且语义裁判判断攻击时，整体返回有风险，无论关键词或正则是否命中；明确覆盖“正则未命中、Judge 有风险”。
- [x] 规则命中但语义裁判判断正常时，返回不确定，保留规则证据和语义判断，不静默覆盖任一方。
- [x] 规则未命中、语义裁判判断正常且全部检查完成时，返回未发现风险；语义裁判返回不确定时，整体为不确定。
- [x] 必需阶段失败、输出无效或检查不完整时返回不确定，并保留已产生的风险发现；严格区别正则正常未命中与执行失败。
- [x] 各阶段至少区分完成、失败和未执行；语义结论与技术执行状态分开表达，空发现列表不等于安全。
- [x] 汇总针对统一阶段结果工作，不依赖具体正则实现；通过公开入口和可控依赖验证分支，不为测试暴露内部汇总器或私有接口，因此无需等待任务 02。
- [x] 测试覆盖汇总矩阵、无效输出、服务异常、可验证和不可验证证据、部分失败保留证据，以及超限不调用语义裁判。
- [x] 不新增规则直接定案、数值加权评分、自动重试、超时或阻断策略；检测结果由外部处置层使用。

## Comments

实现已完成。通过公开引擎入口、真实本地 YAML、可控 Judge/传输及本地 HTTP 服务验证；规范与规格两路审查均无发现。
