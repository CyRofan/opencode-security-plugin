# 05: 建立可重复的文本投毒评测

**What to build:** 安全维护者可以显式运行完整文本检测引擎，对投毒指令及正常对照样本重复评测，查看误报、漏报和耗时，验证关键词、正则及真实语义裁判共同工作的效果。

**Blocked by:** 02 — 接入正则规则与原文证据；04 — 接入真实模型 Judge。

**Status:** resolved

- [x] 提供带预期语义标签的评测样本，覆盖明确恶意指令、安全教程引用、正常工具结果、未命中规则的改写攻击，以及中英文和混合文本。
- [x] 明确每类样本的判定意图，避免仅根据规则是否命中定义真实攻击标签。
- [x] 通过与正常调用相同的公开引擎入口执行三类检测，使用本地 YAML 快照和已配置的真实语义裁判，不另建与产品行为分叉的检测流程。
- [x] 真实模型评测需显式配置并单独执行，支持重复运行；记录规则快照版本、所用模型、运行次数及可解释的结果摘要，供后续对比。
- [x] 报告误报和漏报的定义、计数及计算分母；不确定和技术失败单独统计，不将它们悄悄计为正确，也不凭空设定尚未约定的通过阈值。
- [x] 记录整体及适用阶段耗时，观察慢请求，不将耗时统计转换为检测超时或正则执行时限。
- [x] 不要求真实模型每次输出完全相同；确定性规则及汇总回归使用可控语义裁判，保持日常测试稳定且不依赖网络。
- [x] 验证完整组合中“正则未命中、Judge 有风险”仍得到有风险；同时保留正常引用冲突、服务故障和检查不完整的独立状态。
- [x] 提供运行、重复评测及解读报告的说明；引擎仍不自行保存待检全文或写检测日志，评测输出不泄露凭据或非样本会话内容。
- [x] 现有测试、类型检查以及本功能确定性测试通过；使用可控传输验证评测流程，真实服务不可用时明确报告未完成真实评测，不伪造结果。
- [x] 不扩展到持久记忆文件、完整 ATR 导入、hook 正文提取、流式输出拦截、资源预算统计或自动阻断。

## Comments

实现已完成。通过公开引擎入口、真实本地 YAML、可控 Judge/传输及本地 HTTP 服务验证；规范与规格两路审查均无发现。

评测命令及统计行为已通过本地服务验证；未配置并运行外部真实模型效果评测，不声称任何模型准确率。
