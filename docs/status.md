## 当前能力

| 范围 | 状态 |
| --- | --- |
| 用户正文 | session.prompt 提取当前正文，以固定 user-input 来源调用独立文本引擎，不读取历史、附件或技能内容。 |
| 检测与处置 | 关键词／正则提供证据，一次 Jev Choice 汇总；最终 malicious 整条固定替换，未决或检查未完成保留正文并明确告警，不拒绝提交。 |
| 规则 | 七条本地规则覆盖六类用户输入模式，有中英文及混合正反样本和上游修订说明；不承诺完整 ATR 或穷尽攻击。 |
| 通知 | 已连接 TUI 经实时 RPC 显示固定提示，另保留脱敏服务器日志；无断线补投，通知失败不撤销替换。 |
| 独立引擎 | 本地 YAML 固定快照、关键词／正则、Jev 原生三分类、响应校验、规则证据、阶段状态、概率及实际模型版本。 |
| 配置与生命周期 | 显式加载 Jev 配置，进程变量优先；根 index／tui 用于本地加载，npm exports 指向同一实现，具备注册与订阅清理。 |
| 其他入口和域 | 工具返回、上下文等记忆投毒入口及工具滥用、资源过载、RCE 仍为 not-implemented，不把空发现当安全。 |

调用、配置和故障排查见[文本引擎](text-engine.md)，宿主输入替换与提示见[用户正文检测](user-input-poisoning.md)，数据路径见[架构](architecture.md)。
