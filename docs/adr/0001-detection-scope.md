# 检测范围与规则兼容边界

初始阶段以 OpenCode v2 插件 API 搭建运行时检测框架，将记忆投毒实现范围聚焦于工具返回内容污染模型上下文，不覆盖持久记忆文件。

2026-10-22 根据用户明确变更，取消以工具返回来源限定整个记忆投毒领域：工具返回污染只是其中一种。首个运行时实现选择用户直接提交正文，在 session.prompt 检测并告警，保留原文，不自动阻断。工具返回和上下文 hook 保持占位；本轮不做附件、技能、会话历史关联或持久记忆文件防护。领域定义与实现覆盖面分别说明，避免把更广的名称误解为已有完整防护。

规则先采用项目最小 YAML 模型并保留 ATR 适配入口，不直接承诺完整 ATR 兼容。直接导入原始规则需要承接其条件求值和字段语义；当前优先确认 hook 与检测域的边界。后续扩大范围时应明确更新此决定。
